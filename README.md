A simple and elegant Note Taking Web App built using HTML, CSS, and JavaScript.
It allows users to create, edit, delete, search, and store notes in the browser using localStorage.

🚀 Features

✅ Add new notes with a title and content
✅ Edit existing notes by clicking on them
✅ Delete selected notes using checkboxes
✅ Clear all notes at once
✅ Search notes by title or content
✅ Persistent storage — notes are saved even after refreshing or closing the browser

🛠️ Technologies Used

HTML5 – structure of the app

CSS3 – modern, responsive design and styling

JavaScript (ES6) – app functionality and logic

LocalStorage – for saving notes in the browser
